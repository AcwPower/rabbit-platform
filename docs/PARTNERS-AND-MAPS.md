# 找队友与热门地图（2026-10-26）

找队友与老板招募分开管理。打手、祭司都能发布招募，目标可选打手或祭司。祭司还可发布求职卡，必须填写活花/死花和每小时收费（人民币最多两位小数，游戏币为整数）。地图、职业、补充要求选填，已保存角色可快速带入。

## 组队流程

1. 招募卡由队友申请；求职卡由邀请方发出邀请。
2. 卡片发布者同意意向后，双方才可查看已授权微信。此时状态为 `accepted`，未入队。
3. 双方在微信确认安排后，队长勾选“已添加微信并确认组队安排”，再确认入队。平台不能自动核实微信好友关系。
4. 招募卡的发布者是队长；祭司求职卡的邀请方是队长。后端根据卡片类型判断权限，客户端不能自选队长身份。
5. 入队记录为 `joined`，记录确认时间。队友记录可在“找队友”的收到/已发意向或“我的 → 队友记录”查看。

独立找队友卡不改动老板坑位。老板招募表单现在直接填写需要几位老板；队友配置为需要龙骑、需要祭司或无需招募。前两项会在同一事务内发布对应队友卡，并为一位队友预留位置；同意和确认队友入队均不会消耗老板名额。龙骑招募只接受自报职业为龙骑/龙骑士的申请，仍需线下核实身份。关联招募确认一位队友后停止招募。编辑、下架和管理隐藏会同步关联卡片；无需招募会关闭关联卡片，保留历史意向。删除老板招募的联系方式时也删除关联卡片的复制联系方式。

卡片最多同时发布 5 张。意向最长有效 24 小时且不超过卡片有效期。同一账号对同一卡片不能重复发起有效意向；拒绝、取消或过期后可重新申请。停止招募会取消待处理意向，已同意意向仍可在卡片有效期内由队长确认；下架、隐藏或过期后禁止继续入队。

联系方式加密保存，默认仅同意后的双方可见；可主动公开，也可删除。取消后撤销此次意向的联系授权。卡片过期七天后自动清除联系方式。隐藏或账号停用时停止展示匹配双方联系方式。管理员可隐藏找队友卡，用户可举报。

## 接口与数据

新增 `partner_cards`、`partner_applications` 两张表，迁移 `d78a42b61e09` 接续 `c29b81e3a640`。原有账号、注册截图、招募、求车和撮合数据保持不变。

- `/api/partners/cards`：浏览、筛选和发布。
- `/api/partners/cards/{id}`：详情和编辑，版本冲突返回 409。
- `/api/partners/cards/{id}/status`：停止招募或下架。
- `/api/partners/applications`：请求或邀请。
- `/api/partners/applications/{id}/{accept|reject|cancel|join}`：处理意向。`join` 需要 `{ "wechat_confirmed": true }` 且只能由对应队长操作。
- `/api/partners/me`：自己的发布、收到意向、已发意向。
- `/api/partners/contacts/{partner|partner_app}/{id}`：删除自己的联系方式。

所有写入复用现有登录、CSRF、同源、频率和幂等保护。联系方式不会保存在幂等重放快照中，前端通过详情 GET 重新获取权限和联系方式。

## 招募表单补全（2026-10-26）

最低经验以万为单位使用整数步长，默认仍为 10；包经验的「万」作为固定输入框内单位，按小时显示「元」。开始时间提供「此时」按钮，使用北京时间；每次修改开始时间自动建议六小时后的结束时间，支持跨午夜，结束时间仍可手动修改。编辑已有卡片时保留保存的时段，直到用户修改开始时间。老板招募和找队友共用该时间控件。更多设置移除主力打手人数，既有记录的队伍人数数据继续保留。
