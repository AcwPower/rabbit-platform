# V1 导航、申请提醒与账号资料

- 第一版隐藏队友招募、祭司求职及发布队伍中的队友配置和等级要求。`TEAMMATE_RECRUITMENT_ENABLED` 默认 false；前端读取 `/api/meta` 的功能开关，服务端同时拒绝未开放的队友接口及新建关联招募。已有队友卡片和意向不删除；已有队伍编辑时保留历史预留位，不自动创建或更新关联招募。
- 登录后全站每 5 秒检查 `/api/notifications`，页面隐藏时降为约 30 秒；浏览器节能策略可能进一步延迟。仅统计自己发布且仍有效的卡片下待处理、未过期的申请。数量独立于记录列表分页，拒绝、同意、撤回、过期或下架后消失。
- 新申请显示可点击横幅、顶部铃铛角标、「我的记录」和「收到申请」数量，以及网页标题数量。浏览器首次交互后启用 Web Audio 双音提示，可在顶部静音。关闭网页不接收通知。按账号和申请类型存储去重游标，刷新不会反复响铃；打开申请不等于处理申请。
- `/api/profile` 仅本人可读。微信和二维码加密保存在 `account_contacts`，首次保存开始 7 天限制；同内容重存不重置时间。修改时锁定账号防并发，仍有效、未删除的卡片和申请联系方式同步更新，保留原公开/私密授权。卡片、上车及队友发布接口使用账号微信，禁止绕过资料入口更换联系方式。匿名老板仍按单条记录保存联系方式。
- 迁移 `f39a2e708b16` 继承每个老账号最近一份尚有效、未删除的微信资料。迁移不改变原联系人授权，不写明文；首次上线允许一次更正，之后间隔 7 天。
- 角色资料在「我的资料」只读；原自助新增、删除接口返回 403。用户可向管理员提交修改请求，同一账号只能有一份待处理请求。管理员在账号管理修改指定用户的指定角色，必须填写原因并记录审计，原始 OCR 注册截图和识别快照不变。管理员仍通过举报与申诉回复处理结果。
- 本地浏览器 QA 使用 `vite.qa.config.js` 临时内存数据和提示音计数器，不触及线上申请；该配置不进入发布包。后端回归仅在专用 `*_test` MySQL 数据库执行。

验证：108 项后端回归通过；13 项前端单元测试通过；迁移回填在独立测试库验证成功。浏览器本地模拟通过横幅直达申请、处理后清除角标、响铃去重、静音、微信保存锁定、发布表单自动带入、角色只读、嵌套弹窗返回和 320/390 像素布局检查。

线上部署：`20261026-notifications-profile-v1`，前端资源 `index-C9WR_RSG.js`；部署前备份 `/var/backups/rabbit/20261025T192144Z`。公网功能开关为 false，私有资料和通知接口对游客返回 401，队友接口返回 404。线上首页、资料入口、注册角色默认填入和发布表单已检查，API/OCR/MySQL/HTTPS 健康。

第一版文案统一为打手与老板组队，登录说明、空列表、发布成功和上车流程同步调整。花类型筛选、详情花标签和新评价中的花服务标签随队友功能开关隐藏。发布按钮移到桌面/平板搜索工具栏右侧，手机与栏目说明同排；已检查 1280、1024、390、320 像素宽度和发布入口。
